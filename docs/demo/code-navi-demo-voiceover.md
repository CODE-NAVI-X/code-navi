# Code Navi 项目演示视频人声稿与录制分镜

## 使用方式

本稿以参考成片的四段式节奏为模板：开场说明问题和产品定位，然后依次演示工作区与学习、代码实践与复盘、科研引导与证据边界。录制时只使用一个连续案例，避免在不同页面之间反复切换主题。

建议案例：在“Python 程序设计”工作区创建“掌握 Python 分支与循环，并完成一次可验证练习”这一 Task；学习主题使用“Python 闰年判断的分支逻辑”；练习题选择内置的“闰年判断”。科研部分以“我想研究初学者在条件分支中容易出现哪些错误，以及如何设计练习”作为科研兴趣。这样，学习、练习、复盘和科研都能围绕同一件事展开。

建议录制长度为 3 分 35 秒左右。人声稿约 1,012 个汉字，按 280 至 300 字每分钟录制；字幕不逐字照搬，可每句话压缩成一行重点。

## 人声稿

### 开场 00:00–00:18

计算机专业学习中，知识讲解、代码练习和科研训练常常彼此割裂：学会了概念，却不会把它写成程序；完成了练习，也不知道错误反映了什么。为此，我们开发了智教码航 Code Navi，一个面向自主学习、代码实践和科研探索的智能研学平台。

### 第一部分 工作区与任务 00:18–00:48

首先进入工作台。系统以工作区组织一门课程、一个项目或一项研究，再用 Task 记录当前目标。这里我们在 Python 程序设计工作区创建任务：掌握 Python 分支与循环，并完成一次可验证练习。创建后直接进入学习页面。这样的设计让每次学习都有明确目标，并能在刷新页面或下次进入时恢复，而不是一次问答结束后丢失过程。

### 第二部分 知识学习与理解检查 00:48–01:34

现在输入“Python 闰年判断的分支逻辑”。学习模块可以从概念、问题或一段材料直接开始，也可以按计算机方向探索。系统围绕当前主题生成分步讲解，并保留学习会话、笔记和来源信息。接着进入理解检查，完成一道题目。测验成绩由服务端的题目与评分依据生成；学生也可以标记暂时不理解的位置。当前主题还能生成逐页演示文稿，便于复习和课堂汇报。这里的重点是，系统记录真实学习活动，而不只依据模型判断学生是否掌握。

### 第三部分 代码实践与学习复盘 01:34–02:43

从动手实践进入闰年判断题。我们先提交一个只判断“四的倍数”的版本。程序能够运行，不代表答案正确；判题结果会分别展示公开测试、隐藏测试的通过状态，以及运行时间、内存和退出码。隐藏测试不返回输入和期望输出，保证题目评价不在浏览器端泄露。

修改世纪年份和四百年整除的条件后再次提交，系统返回通过结果。代码实际执行由受控的 Python 运行环境完成，题目正确性由服务端测试决定；AI 只在学生主动开启时解释错误、提供调试线索，不会覆盖执行事实或直接给出完整答案。

随后进入知识复盘。系统把真实的测验作答、学生主动标记的困惑和本次练习结果聚合为知识缺口。我们可以从错误类型回到针对性的讲解或练习；同时，这些活动也会回流到当前 Task 时间线，形成可追溯的学习记录。

### 第四部分 科研引导与证据边界 02:43–03:22

对于希望继续探索的学生，可以进入科研引导。科研智能体姜姜不会在信息不足时直接生成课题，而是通过对话逐步澄清研究主题、动机、方法、数据需求和预期成果，形成结构化研究画像与研究计划。

当需要文献时，系统先展示检索计划；只有学生确认后，才从受限学术来源获取论文元数据和可用摘要，并保存为证据包。页面明确区分来源事实、系统推断和待核验项。实验方案、代码草案和论文蓝图都只是建议或预览，不会自动联网、执行代码、写入项目或生成科研结论。

### 结尾 03:22–03:35

至此，同一项任务已经留下学习讲解、代码实践、知识复盘和科研探索的连续记录。智教码航用工作区组织长期目标，用真实执行和证据约束智能建议，帮助学生把“学、练、测、评、研、改”连接为可恢复、可验证的探究过程。演示结束，感谢观看。

## 录制前的最小准备清单

1. 准备一个干净的演示账号或浏览器资料，并预先创建“Python 程序设计”工作区；录制时只新建上述 Task。
2. 预先确认 Piston 状态为可用，且“闰年判断”题可稳定返回公开与隐藏测试。录制时准备两份代码：错误版只判断 `year % 4 == 0`，正确版补上世纪年与四百年规则。
3. 预先生成一次学习讲解、测验、困惑标记和练习结果，确保复盘与 Task 时间线有可展示的真实记录；正式录制时可用跳切压缩生成等待。
4. 预先建立一个科研会话和一份稳定的已保存证据包。若在线 Provider 或学术检索不可用，录制已保存的画像、计划和证据卡，并如实保留“来源范围”和“待核验”标签。
5. 开场和结尾使用工作台或 Task 时间线，中间四段固定使用“任务 → 学习 → 实践与复盘 → 科研”的页序；这就是后续快速换主题、换题目即可复制的视频模板。
