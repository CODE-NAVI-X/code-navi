# Learning Entry

学习入口页

| 状态 | 当前计划 |
| --- | --- |
| 已实现，本地验证完成 | [学习入口页改版计划](../plans/learning-entry-redesign.md) |

## 1. 产品目标

学习页首先帮助用户直接表达想理解的内容、恢复最近学习或按计算机方向探索。方向选择是可选入口，不再作为开始学习的前置步骤。

## 2. 页面结构

学习入口页固定由三个一级区块组成，顺序如下：

| 区块 | 固定标题或文案 | 用户可观察行为 |
| --- | --- | --- |
| 发起学习 | `今天想理解什么？`；输入提示为 `搜索概念、问题或粘贴一段材料……` | 用户可以直接提交概念、问题或材料并进入学习工作区，不需要先选择方向 |
| 恢复学习 | `继续最近学习` | 展示最近可恢复的学习项；例如 `Q-learning 更新过程`、`TCP 拥塞控制`，点击后恢复对应学习上下文 |
| 方向探索 | `探索计算机方向` | 展示六大领域的稳定导航和可多选的方向胶囊，用于发现主题，不阻塞直接搜索 |

六大领域使用以下稳定名称，并作为一级导航长期保持稳定：

| 方向入口一 | 方向入口二 | 方向入口三 |
| --- | --- | --- |
| AI 与数据 | 计算机系统 | 软件与编程 |
| 理论与数学 | 网络与安全 | 硬件与体系结构 |

响应式布局可以改变方向入口的行列数量，但不得改变三个一级区块的顺序和层级。

## 3. 搜索与恢复行为

1. 搜索框始终可用。领域和方向胶囊的选择结果只形成探索上下文，不能成为提交学习请求的必需条件。
2. 概念、问题和材料都进入同一个学习工作区。材料输入必须按原始学习请求处理，不得在前端静默截断或伪装成已经提炼的概念。
3. `继续最近学习` 读取真实、已持久化且当前资料可访问的学习记录，不使用固定示例冒充历史。没有记录时保留该区块并显示简短空状态。
4. 最近学习项按最近活动排序，首屏只展示少量条目。点击条目恢复已有学习上下文，不重复创建同一学习结果。
5. 页面带有 Workspace 或 Task 上下文时，发起与恢复学习均保留该上下文；入口改版不改变 Activity 的归属规则。

## 4. 计算机方向探索

1. 六大领域是一级稳定导航。切换领域只改变当前可探索的方向胶囊和主题建议，搜索框持续可用。
2. 每个领域下展示可多选的方向胶囊。用户可以跨领域保留多个已选方向，并随时逐项取消或一次清空。
3. 领域与方向采用多对多归属：一个方向可以同时属于多个领域，系统以同一个稳定方向标识在不同领域下展示，不复制成多个互不关联的方向，也不建立严格树形父子关系。
4. 当前学习页已有方向全部归入六大领域下的多选方向胶囊，不再提供重复的“查看所有方向”入口。
5. 已选方向在搜索框下方同步显示为胶囊，每个胶囊右侧提供独立取消按钮；取消只移除对应方向。
6. 当前激活领域与已选方向集合共同组成探索上下文。探索上下文只用于筛选、排序或补充主题建议，不写入学习进度、Learning Activity、Notebook、Task 状态或学习工作区恢复快照。
7. 用户提交的概念、问题或材料始终是学习请求的事实来源。探索上下文不得替代输入，也不得产生“正在学习、已完成或已掌握某领域”的状态。
8. 用户取消探索方向时不删除查询、讲解结果、笔记或最近学习记录。

## 5. 页面口径

学习入口统一使用“学习入口页”“学习工作区”“六大领域”“方向胶囊”和“探索上下文”。页面不使用阶段编号描述方向选择与知识解析，也不把领域或方向胶囊选择表述为学习状态或进入学习的必要步骤。

讲解结果、PPT、配套练习、学习笔记以及 Learning 向 Research 的现有下游行为保持不变。Practice 的产品入口、规范路由和兼容迁移按 [Learning–Practice Integration Spec](learning-practice-integration.md) 执行；系统中的 Practice Capability 和在线编译安全边界保持独立。

## 6. 验收条件

1. 无 Task 直接进入 `/learning` 时，首屏按顺序显示三个一级区块，搜索框无需方向选择即可提交。
2. 带 Workspace 或 Task 上下文进入时，页面保留上下文，提交结果仍按现有规则创建 Learning Activity。
3. 最近学习展示真实记录；有记录时可恢复，无记录时有明确空状态，加载失败时不显示为无记录。
4. 六大领域名称与本 Spec 一致并作为一级稳定导航；每个领域可以展示多个可多选的方向胶囊。
5. 同一方向可以归属多个领域，并在各入口使用同一个稳定标识；验收不以严格树形层级为前提。
6. 原有方向均出现在对应领域的方向胶囊中，页面不显示“查看所有方向”入口。
7. 已选方向在搜索框下方显示为可独立取消的胶囊；取消选择不改变学习工作区、最近学习、Task、Activity 或 Notebook。
8. 概念、问题和材料输入均有明确的加载、成功与失败状态；超出后端可接受范围时给出可操作提示，不静默丢失内容。
9. 桌面与窄屏均保持三个一级区块的阅读顺序、键盘可达性和可辨识焦点。

## 7. 当前限制

`POST /api/v1/learning/explain` 接受最多 64 个字符的概念、问题或材料片段；页面在提交前显示长度并对超限材料给出裁剪提示。`GET /api/v1/learning/recent` 通过当前本地资料范围内的 Learning Activity 定位原始 Notebook 结果，返回可恢复项或明确的来源失效状态。
