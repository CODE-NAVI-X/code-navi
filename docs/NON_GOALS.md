# 当前非目标

以下事项不属于当前 CLI 基线的完成范围：

- 为单一业务需求破坏 `src/kernel/` 的平台无关契约；
- 把平台 SDK、Provider 原生类型或确认 UI 写入助手声明；
- 默认启用写入、执行、联网、发布或破坏性工具；
- 把通用 shell 当作代码学习和在线判题的默认执行工具；
- 声称当前问题分支可以跨进程恢复或构成长期记忆；
- 将 Event JSONL 直接当作任务数据库、身份系统或完整聊天历史；
- 声称 Task Workspace、代码沙箱、正式判题、OpenMAIC、GitHub 接入或 GUI 已经实现；
- 未经评估的多 Agent 编排、自动评分、自动发布或自动研究结论；
- 在缺少来源和人工复核时输出确定性的教学或科研结论；
- 为方便单一业务而绕过 kernel 的注册、权限、上下文或审计契约。

非目标不等于永远不做。某项能力进入实现前，需先定义业务负责人、风险边界、人工复核点、最小验收和回滚方式。
