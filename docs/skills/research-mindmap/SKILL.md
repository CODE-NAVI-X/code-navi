# 研究思维导图

## 版本

`research-mindmap.v1` 前端呈现契约（本地演示版）。

## 用途

将已经保存的科研画像、规则计划和受限证据整理为“摘要卡 → 专注导图工作区”的可读总览。摘要卡只显示主题、状态计数和展开入口；用户展开后才渲染可缩放、可拖拽的节点连线图，并按需打开节点详情。

## 输入与输出

输入为既有 `research-mindmap.v1` 的 `root_node_id`、`nodes`、`edges`、状态和来源。输出是本地 UI 与 SVG：根、一级、二级节点按层级布局，详情抽屉展示节点说明、事实边界和已保存来源。不会修改后端数据或添加关系。

## 规则层与模型层边界

后端规则层唯一决定节点、edges、状态和来源范围；前端只用既有 `@xyflow/react` 与 `@dagrejs/dagre` 布局和展示。导图区分事实、建议、待验证、来源证据和风险；不调用模型，不把摘要外内容升级为事实。

## 权限、来源与副作用

不联网、不读论文全文、不调用模型、不写文件、不写会话、不执行代码。详情中的来源链接只在用户主动点击后以新标签页打开；展开、筛选、缩放和点击节点不会触发检索或任何写操作。

## 失败与规则降级

无计划或无证据时摘要卡和图谱仍显示安全的待验证节点。React Flow 渲染异常时回退为本地节点详情清单，不影响科研页面其他面板。当前支持真实 SVG；PNG 尚未实现，保留为后续增强。

## 测试样例

- 后端 `nodes + edges` 映射为真实 React Flow 节点、连线与 Dagre 层级布局。
- 默认仅显示摘要卡，展开后画布至少 520px（窄屏至少 420px），详情抽屉仅在点击节点后出现。
- 证据节点展示已保存来源、访问时间和信息范围；无来源时不联网补全。
- SVG 含真实节点框、连线、状态颜色与文字，且不含 Key、会话全文或论文全文。

## 外部参考与许可证

使用项目已安装的 `@xyflow/react` 与 `@dagrejs/dagre`（均为 MIT）实现交互图和层级布局；没有新增第三方图谱依赖，也没有复制外部示例、资源或运行时图数据。
