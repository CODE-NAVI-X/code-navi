# 论文初稿与结构化审稿

## 版本

`paper-draft-review.v1`

## 用途

只分析用户主动粘贴到当前本地会话的 Markdown/纯文本初稿，生成有事实边界的结构化审稿建议。

## 输入与输出

输入为 `PaperDraft` 和用户明确的审稿请求；输出为 `PaperReview`、`ReviewFinding` 与可恢复的 `RevisionTask`。

## 规则层与模型层边界

规则层判断章节缺口、证据边界、严重度和恢复。DeepSeek 如可用，仅以严格 JSON 改善既有意见的解释与建议，不能更改 `fact / inference / to_verify`、新增事实、联网或决定发表资格。

## 权限、来源与副作用

不联网、不读 DOCX/PDF 或本地路径、不写入用户项目、不执行代码。仅使用用户粘贴文本及会话中已保存的画像、计划、EvidenceBundle 和实验记录；没有生产级文件存储与隐私托管。

## 失败与规则降级

无 Key、超时、网络错误、非法 JSON、字段缺失或超长输出时自动保留规则审稿并标记 `rules_fallback`。

## 测试样例

没有摘要/实验结果/伦理说明的初稿会产生待验证缺口；无实验记录支撑的“显著提升”必须标为 `major + to_verify`。

## 外部参考与许可证

只使用本项目可追溯证据边界设计，没有复制第三方代码、Prompt 或资源，也没有新增运行时依赖。
