# 受控导出论文辅助包

## 版本

`paper-export.v1`

## 用途

用户主动点击后，将当前本地初稿、修订预览、结构化审稿和投稿前检查清单导出为 Markdown 与 JSON 文本辅助包；不是会议或期刊最终投稿格式。

## 输入与输出

输入为最近 `PaperDraft`、`PaperReview`、`PaperRevision` 与 `SubmissionReadinessCheck`；输出为两个 `PaperExportFile` 的 `PaperExportPackage`。缺少前置工件时给出清晰错误。

## 规则层与模型层边界

规则层控制用户显式触发、前置条件、导出范围和敏感信息隐藏。当前没有模型参与；模型不能自动导出、伪造事实、改变事实分类或作出可投稿承诺。

## 权限、来源与副作用

不联网、不读取论文全文、不写入项目、不安装依赖、不执行代码、不投稿。服务端仅返回内存文本，浏览器在用户点击后下载；本版本不生成 ZIP、DOCX、PDF 或 LaTeX。

## 失败与规则降级

未生成审稿、修订预览或投稿前检查时拒绝导出；会隐藏 Key 与私有路径，不导出会话历史、数据库、缓存或项目文件。

## 测试样例

未确认导出应被校验拒绝；完成前置流程后返回 Markdown 与 JSON，内容不含 API Key 和 `C:\\Users\\`。

## 外部参考与许可证

采用浏览器 Blob 下载及项目的最小权限边界；未复制外部导出、投稿或模板框架，无新增第三方依赖。
