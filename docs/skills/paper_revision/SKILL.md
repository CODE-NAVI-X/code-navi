# 论文修订预览

## 版本

`paper-revision.v2`

## 用途

仅为用户明确接受的单条修订任务生成可定位的候选段落，并在用户再次确认后创建可比较、可恢复的新版本；绝不覆盖原稿。

## 输入与输出

输入为 `PaperDraft`、状态为 `accepted` 的 `RevisionTask` 与 `RevisionSuggestion`；候选包含原文片段、段落锚点、候选文本、依据、事实边界和待验证项。用户接受或手动编辑候选后输出 `PaperRevision`，含父版本、任务/建议 ID、变更摘要和 diff。

## 规则层与模型层边界

规则层保留原版本、控制任务状态、段落定位、用户确认、事实边界和版本保存。DeepSeek 仅可为已接受任务生成严格 JSON 的候选文本、解释和待验证项；不能补造引用、实验数值、样本量、显著性或结论。无 Key、超时、网络失败、非法 JSON、越界内容或定位失败时回退规则候选。

## 权限、来源与副作用

不联网、不写入用户项目、不安装依赖、不执行代码。候选只有用户点击接受后才进入新版本；用户可手动编辑候选，来源会标为“用户手动编辑”。

## 失败与规则降级

未接受任务、候选定位失败或候选越过事实边界时明确拒绝落版；无需模型，模型不可用不会影响规则候选、人工编辑与版本恢复。

## 测试样例

任务未接受时返回冲突；接受任务后生成候选；手动编辑并接受后生成新版本，同时保留原稿、父版本、关联任务/建议与 diff。

## 外部参考与许可证

使用本项目可追溯、人工确认的版本管理原则；没有复制外部审稿或自动改写框架，也没有新增依赖。
