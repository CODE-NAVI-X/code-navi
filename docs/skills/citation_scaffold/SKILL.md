# 用户确认的受限证据引用与完整性检查

## 版本

`citation-scaffold.v1.2`

## 用途

为当前会话中用户主动选择的受限 EvidenceBundle 来源生成引用占位，执行可恢复的完整性检查，并整理稳定、可复制、可追溯的非正式参考文献草案。结果展示来源—章节映射、重复选择、未确认插入占位、元数据缺口和人工核验项；不声称来源支持了正文主张，也不声称符合投稿格式。

## 输入与输出

输入为当前会话已保存的论文元数据/摘要范围、用户明确选择的论文、目标文档、章节、段落锚点和人工插入状态。输出包括 `CitationCandidate`、`SelectedCitation`、`ReferenceEntryDraft`、`CitationQualityCheck` 与 `ReferenceDraftPackage`。草案按保存顺序稳定排列，每条关联 `SelectedCitation` 和原始来源链接；章节覆盖统一为 `inference`，元数据、摘要范围和人工核验缺口为 `to_verify`。

## 规则层与模型层边界

规则层负责当前会话来源校验、用户选择、持久化、引用占位、重复检测、章节映射、稳定文本整理和 `fact / inference / to_verify` 边界。当前完全规则化；无模型或模型失败不影响检查与草案，也不使用模型补全任何书目信息或论文事实。

## 权限、来源与副作用

不联网、不读全文、不写入用户项目、不自动插入或改写原稿、不执行代码。仅读取当前会话已经保存的受限来源和用户明确选择；检查必须由用户点击触发，刷新只恢复历史结果。复制动作只复制展示中的参考文献草案，不包含用户备注、会话消息、密钥、私有路径或数据库内容。

## 失败与规则降级

无来源或未选择来源时返回带解释的安全空状态；来源不属于当前会话时拒绝。作者、年份、来源链接、DOI/arXiv 标识缺失，以及只有元数据没有摘要时，均显示待核对项，不伪造引用或摘要支持范围。即使元数据完整，每条草案仍明确标为“非正式格式化参考文献”。

## 测试样例

选择已保存 arXiv 论文并关联“相关工作”后，可显式运行检查并恢复历史结果；重复选择、未确认人工插入和元数据缺失会进入 `to_verify`。跨会话来源不可见，检查接口不发起网络请求或修改论文原文。

## 外部参考与许可证

仅使用项目内 EvidenceBundle 的受限来源与可追溯边界；没有引入或复制第三方引用风格、BibTeX 模板、代码、Prompt 或依赖。
