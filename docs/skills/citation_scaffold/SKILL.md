# 用户确认的受限证据引用占位

## 版本

`citation-scaffold.v1`

## 用途

为当前会话中用户主动保存的受限 EvidenceBundle 生成可见、可编辑位置说明的引用占位与参考文献雏形，供作者和导师核对；不声称符合任何投稿格式。

## 输入与输出

输入为已保存的论文元数据/摘要范围、用户选择的论文、目标文档、章节和段落锚点。输出为 `CitationCandidate`、`SelectedCitation` 与 `ReferenceEntryDraft`，包括信息范围、元数据完整度和待核对项。

## 规则层与模型层边界

规则层唯一负责当前会话来源校验、用户选择、持久化、引用占位、参考条目和 `fact / to_verify` 边界。当前完全规则化；不使用模型补全任何书目信息或论文事实。

## 权限、来源与副作用

不联网、不读全文、不写入用户项目、不自动插入或改写原稿、不执行代码。仅读取当前会话已经保存的受限来源元数据和摘要范围；只有用户主动选择时才保存本地选择。

## 失败与规则降级

无来源或未选择来源时返回空条目；来源不属于当前会话时拒绝。作者、年份、来源、DOI 或 arXiv 标识缺失时显示待核对占位，不伪造引用。

## 测试样例

选择已保存 arXiv 论文并关联“相关工作”后，可恢复占位与条目；取消选择后条目消失。缺失作者、年份或来源时输出 `to_verify`，且接口不发起网络请求。

## 外部参考与许可证

仅使用项目内 EvidenceBundle 的受限来源与可追溯边界；没有引入或复制第三方引用风格、BibTeX 模板、代码、Prompt 或依赖。
