# 投稿前检查

## 版本

`submission-readiness.v1`

## 用途

对本地已保存的论文初稿、修订预览、审稿任务和证据状态给出可审阅的投稿前检查清单；不代表导师结论、同行评审或投稿资格。

## 输入与输出

输入为 `PaperDraft`、最近 `PaperReview`、最近 `PaperRevision` 与本地证据是否存在；输出为 `SubmissionReadinessCheck`，包括 `not_ready / needs_review / checklist_complete`、阻塞项、警告、人工核验、事实边界和下一步建议。

## 规则层与模型层边界

规则层检查章节、待验证占位符、无证据主张、匿名线索、伦理/数据许可、图表材料和 venue 格式待确认项。当前不调用模型；未来模型也不能改写事实分类、完成状态或给出“已经可以投稿”的结论。

## 权限、来源与副作用

不联网、不读取论文全文、不写入用户项目、不自动下载、不安装依赖、不执行代码、不投稿。用户点击后才生成并在当前本地会话保存检查结果。

## 失败与规则降级

证据、修订预览或材料缺失时安全返回 `to_verify`；不伪造实验数值、引用、匿名合规、伦理许可或 venue 格式结论。

## 测试样例

无实验支撑的“显著提升”应保留为 `to_verify`；检查能恢复；未生成修订预览会显示阻塞项。

## 外部参考与许可证

沿用项目的可追溯、人工复核原则；未复制外部投稿检查框架、资源或 Prompt，且未新增第三方依赖。
