# 学习入口页改版计划

| 关联 Spec | 当前状态 |
| --- | --- |
| [Learning Entry](../specs/learning-entry.md) | 已实现，本地验证完成 |

## 1. 目标与完成条件

将 `/learning` 的默认入口改为“发起学习、继续最近学习、探索计算机方向”三个区块。完成时，直接搜索、最近学习恢复、六大领域稳定导航、可多选方向胶囊、搜索框下方的已选方向胶囊以及带 Workspace/Task 上下文进入均跑通最小闭环，现有讲解结果和下游功能不回退。

## 2. 实施范围

### 2.1 输入与最近学习数据

先验证 `POST /api/v1/learning/explain` 的输入范围和 Workspace Activity 可恢复字段。概念和问题继续复用现有 explain 路径；材料输入若超过现有短文本契约，则在真实请求闭环中扩展请求字段和服务端校验，不由前端静默裁剪。

最近学习优先复用服务端已持久化的 Learning Activity 与原始学习产物引用，增加一个有界查询以返回标题、最近活动时间和恢复定位。查询失败、空结果和来源失效使用不同页面状态。

预计涉及：

1. `src/code_navi/learning/` 与相关 FastAPI schema/router；
2. Workspace Activity 查询服务及前端 API 镜像；
3. `frontend/lib/api/learning.ts`、`frontend/lib/api/workspaces.ts`。

### 2.2 学习入口与方向菜单

重构 `frontend/app/(student)/learning/page.tsx` 的空闲首屏，按 Spec 放置三个一级区块。现有方向数据全部归入六大领域下的可多选方向胶囊，不保留重复的完整方向菜单；已选方向同步显示在搜索框下方，并可逐项取消。

方向数据拆为稳定领域集合、稳定方向集合和多对多归属映射。方向使用单一稳定标识及 `domain_ids` 关联多个领域，不使用单一 `parent_domain_id` 或按领域复制方向记录。初始实现可以继续使用前端静态数据，但数据形状必须允许后续改为服务端来源而不改变产品语义。

当前激活领域和已选方向标识集合只保存在学习入口组件的探索上下文中，用于筛选与排序主题建议。`frontend/lib/store/learning-store.ts` 只保存恢复学习工作区所需状态，移除当前 `selectedDirectionId` 学习快照字段；探索上下文不写入 explain 结果、Notebook、Learning Activity 或 Task 状态。

### 2.3 最小验证

1. 直接进入 `/learning`，不选方向提交概念和问题；用超过短文本范围的材料验证明确提示或扩展后的真实请求。
2. 分别验证最近学习有记录、无记录、加载失败和来源失效；点击有效记录恢复原学习上下文。
3. 验证六大领域导航、跨领域多选方向胶囊，以及搜索框下方胶囊的同步显示和逐项取消。
4. 从根页面 Task、Workspace 页面和独立 Capability 入口进入 Learning，确认上下文与 Activity 归属不变。
5. 使用至少一个跨领域方向验证多对多归属：不同领域入口展示同一个方向标识，选择结果不产生重复记录。
6. 清除探索上下文后确认查询、讲解结果、最近学习、Notebook 和 Task/Activity 状态均不改变。
7. 运行受影响前端 lint/build 和相关后端测试；全量检查放在上述闭环通过后执行。

## 3. 接口与边界风险

1. 当前页面输入上限和 explain schema 面向知识点短文本，材料输入会触及 API 契约与模型上下文开销；实现时需要以真实长度限制、错误语义和 Provider 成本确定最小扩展。
2. Workspace Activity 目前是安全摘要与来源引用，最近学习恢复必须定位真实 Learning 产物，不能把摘要当作完整结果。
3. Task 上下文进入、独立 Learning 和浏览器已有快照可能同时存在；恢复优先级需要通过现有 URL 与服务端数据试运行确定，不提前冻结为新的跨模块 Contract。
4. 方向跨领域归属后，名称、标识和示例主题必须以方向记录为单一来源；按领域复制数据会造成选择、统计和后续服务端迁移不一致。

## 4. 性能影响

首屏只新增一次有界的最近学习查询；六大领域、方向和多对多归属映射保持本地静态读取。方向胶囊按当前领域过滤，已选方向胶囊复用同一份本地数据，不预取讲解、PPT 或练习内容。材料输入沿用服务端长度限制与显式校验，避免无界请求影响首屏交互和 Provider 开销。

## 5. 退出条件

三个一级区块及其真实交互已经完成本地验证。旧方向首屏、严格树形归属、单选方向学习快照与阶段式口径已从页面和状态命名中移除；前端架构已同步为当前事实。
