# 实验结果证据包与论文蓝图：本地实施计划

> 状态：已批准的本地待测阶段；不推送、不创建或修改 PR。

## 目标与边界

在既有“科研澄清 → 研究计划 → 用户主动受限检索”之后，增加两项可恢复工件：

1. 用户显式提交的 `experiment-evidence.v1`；
2. 只根据已保存画像、研究计划、文献证据和实验事实生成的 `paper-blueprint.v1`。

本阶段不实现论文全文、上传文件、自动检索、自动实验、草稿评审/修订、DOCX/LaTex 导出或自动投稿。

## 实施顺序

1. 先写 API/规则测试，定义实验结果事实、恢复和论文蓝图的安全边界。
2. 增加 Pydantic schema、SQLite 持久化迁移、显式 API 与规则生成器；不在 GET/恢复流程调用模型或网络。
3. 在既有科研页面增加紧凑的结果录入与蓝图查看面板。
4. 新增 Skill 契约和后续论文工作流的设计边界；更新 README、路线图。
5. 运行完整后端、前端、API 与浏览器验证，分别提交“结果证据包”和“论文蓝图/文档”两个本地可回滚提交。

## 验收规则

- `fact` 仅表示用户本次明确提交的内容，且标注“未由系统复核”。
- 未提交的信息、摘要之外的论文结论、统计显著性和资源条件均为 `to_verify`。
- 论文蓝图的实验章节只引用保存的实验结果事实；相关工作只引用已保存的受限来源元数据/摘要。
- 所有网络、文件写入、安装和执行操作保持未实现且不被触发。
