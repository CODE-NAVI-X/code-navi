# 投稿前检查

## 版本

`submission-readiness.v1`

## 用途

在用户明确点击后，对当前本地已保存的初稿、修订预览、审稿意见和证据状态生成检查清单；它不判断录用概率或投稿资格。

## 输入与输出

输入为 `PaperDraft`、最近 `PaperReview`、最近 `PaperRevision` 及是否已有实验/学术证据；输出为 `SubmissionReadinessCheck`，含 `not_ready / needs_review / checklist_complete`、阻塞项、警告、人工核验项和事实边界说明。

## 规则层与模型层边界

规则层负责章节、占位符、未核验主张、匿名线索、伦理/数据许可、材料与 venue 格式提示，以及状态判定。当前不调用模型；任何未来模型只能优化说明，不能将 `to_verify` 改为事实或宣称“可以投稿”。

## 权限、来源与副作用

不联网、不读论文全文、不写入用户项目、不安装依赖、不执行代码、不投稿。只读取当前本地会话的已保存工件；检查只在用户显式请求后保存本地清单。

## 失败与规则降级

没有修订预览、实验记录或受限来源证据时返回明确的 `to_verify` 项；不会补造引用、实验结果、伦理许可或目标 venue 合规结论。

## 测试样例

含“显著提升”且无实验事实的草稿会得到 `not_ready` 与 `to_verify`；刷新后可恢复已保存检查；未生成修订预览时明确列为阻塞项。

## 外部参考与许可证

遵循本项目的事实边界和用户确认原则，不复制外部投稿检查框架、模板或 Prompt；无新增第三方依赖。
