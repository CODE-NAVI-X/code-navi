# 受控导出论文辅助包

## 版本

`paper-export.v1`

## 用途

在用户明确点击后，将当前本地已保存的初稿、修订预览、结构化审稿和投稿前检查组织为浏览器可下载的 Markdown 与 JSON 辅助包；它不是最终投稿格式。

## 输入与输出

输入为 `PaperDraft`、最近 `PaperReview`、最近 `PaperRevision` 和最近 `SubmissionReadinessCheck`；输出为含两个文本文件的 `PaperExportPackage`。缺少任一前置工件时返回明确错误。

## 规则层与模型层边界

规则层要求用户显式触发、限定导出范围并隐藏 API Key 与私有本地路径。当前不调用模型；任何模型也不能自行导出、改写事实边界或声称导出物可直接投稿。

## 权限、来源与副作用

不联网、不读论文全文、不写入用户项目、不安装依赖、不执行代码、不投稿。后端只返回内存文本；浏览器下载是用户点击后的本地行为，不创建 ZIP 或服务端文件。

## 失败与规则降级

没有审稿、修订预览或投稿前检查时安全拒绝；敏感标记和本地路径会被隐藏。不会导出会话历史、数据库、缓存或未选中的研究工件。

## 测试样例

未确认请求不能导出；准备齐前置工件后返回 `.md` 与 `.json`，并验证内容不含 API Key 或 `C:\\Users\\` 私有路径。

## 外部参考与许可证

使用浏览器 Blob 下载与本项目受控数据边界；未复制外部导出、投稿或文档模板代码，且无新增第三方依赖。
