# 论文复现 Pipeline Skill

## 版本

`reproduction-pipeline.v1`

## 输入与输出

输入是同一科研会话中用户主动选择的已保存 EvidenceBundle、论文 URL、规则研究画像/计划与用户提交的 ExperimentEvidenceBundle。输出是可恢复的 ReproductionPipeline、其来源范围和非执行式 Python 学习任务。

## 规则层与模型层边界

Pipeline 完全由本地规则构造，不调用模型。元数据或摘要直接支持的内容才是 `fact`；规则组织出的步骤是 `inference`；摘要外的数据、设置、结论、资源、伦理和复现条件必须是 `to_verify`。

## 权限、来源与副作用

用户主动选择后才能生成。只读取已经保存的数据库工件；不联网、不下载论文全文、不读取私有文件、不写入学生项目、不自动执行代码。

## 失败与规则降级

未选择论文或论文不属于当前会话的已保存来源时拒绝生成。摘要不足时保留待核对项，不补造方案或实验结果。

## 测试样例

验证选中来源归属、摘要范围外降级、任务与用户实验记录关联、持久化恢复，以及生成过程不调用检索服务。

## 外部参考与许可证

不引入外部 Skill、运行时或许可证；仅使用应用已保存的允许来源元数据和摘要。
