# 本地论文初稿与结构化审稿

## 版本

`paper-draft-review.v1`

## 用途

保存用户主动粘贴的 Markdown/纯文本初稿，并将其与已保存研究画像、研究计划、受限来源 EvidenceBundle 和实验结果证据包进行规则优先的结构化对照。

## 输入与输出

输入为 `PaperDraft`（标题、文本、格式）和用户明确的审稿触发；输出为可恢复的 `PaperReview` 与 `ReviewFinding`。每条意见包含严重度、依据、`fact / inference / to_verify`、来源范围和可执行的修订建议。

## 规则层与模型层边界

规则层限定长度、保存版本、章节缺口、事实边界、严重度和恢复。配置 DeepSeek 时，模型只能用严格 JSON 改善已有 finding 的解释和建议，不能新增事实、改写分类、联网或决定通过/投稿。

## 权限、来源与副作用

不联网、不读取 DOCX/PDF 或用户路径、不写入用户项目、不执行代码。来源仅限用户当前本地会话主动粘贴的初稿和已经保存的本地科研状态；当前没有生产级文件存储或隐私托管。

## 失败与规则降级

无 Key、超时、网络失败、非法 JSON、字段不完整或超长输出时，保留基础规则审稿并标记 `rules_fallback`，不会中断会话。

## 测试样例

提交没有摘要、实验结果或伦理说明的初稿；含“显著提升/证明有效”但没有 ExperimentEvidenceBundle 支持的文字必须标为 `major + to_verify`。

## 外部参考与许可证

仅采用本项目已有的证据边界与结构化审阅思想；未复制第三方 Prompt、代码或资源。无新增第三方运行时依赖或许可证负担。
