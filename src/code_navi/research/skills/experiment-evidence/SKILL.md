# 实验结果证据包

## 版本与用途

- 版本：`0.1.0`
- 用途：输出并恢复 `experiment-evidence.v1`。它是用户报告的文本证据包，不是系统运行、复核或上传的原始数据。

## 输入与输出

- 输入：会话 ID、实验名称、目标和用户主动粘贴的文本/表格文本/图表说明；每项选择 `fact`、`inference` 或 `to_verify`。
- 输出：带提交时间、`basis`、`source_scope=user_submitted_text`、研究计划关联和可选已保存文献链接的证据项。

## 规则层与模型层边界

- 规则层确认会话存在、保存用户原文、生成提交依据并恢复记录。
- 本版不调用模型。未来模型只能协助组织表达，不能新增数值、显著性、数据集规模、基线、图表或结论，更不能改变用户确认状态。

## 权限、来源与副作用

- 只访问当前会话的 SQLite 记录与用户本次请求文本；不联网、不读取本地文件、不读取原始实验数据。
- 会写入应用 SQLite 的证据包；不写入用户项目、不安装依赖、不运行代码或命令。

## 失败与规则降级

字段不合法或会话不存在时返回清晰的 HTTP 校验/404 错误。没有模型、网络或外部依赖的成功路径；`fact` 仅表示用户显式报告，始终保留“未由系统复核”的范围说明。

## 测试样例

- `tests/test_research_paper_workflow.py`：保存、恢复自由文本、事实边界与无自动检索。
- `tests/test_migrations.py`：SQLite schema 与 Alembic migration 一致。

## 外部参考与许可证

采用项目内 EvidenceBundle 的可追溯思想；未复制第三方 Skill、Prompt、脚本或资源，未新增外部运行时依赖。
