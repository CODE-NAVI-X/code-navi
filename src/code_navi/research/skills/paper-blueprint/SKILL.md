# 论文蓝图

## 版本与用途

- 版本：`paper-blueprint.v2`
- 用途：在用户明确点击后输出固定五段的论文蓝图，列出每章目标、证据引用、缺口与禁止主张；不生成或投稿论文全文。

## 输入与输出

- 输入：已保存 `ResearchProfile`、规则 `research-plan.v1`、用户主动保存的 `academic-evidence.v1` 及 `experiment-evidence.v1`。
- 输出：候选标题、待确认投稿方向、摘要要求，以及固定五段：摘要/介绍/文献综述/方法/实验。摘要为 ≤200 字的结构化骨架；讨论的风险/可信边界并入实验 `missing_evidence`，结论的收束并入方法 `writing_goal`；同时返回来源引用、缺失证据、禁止主张与投稿就绪度。

## 规则层与模型层边界

- 规则层唯一控制证据可用性、来源范围、事实标签、禁止主张和投稿就绪度。
- 蓝图由已配置模型生成并经规则校验；模型只能产出 `inference` 或 `to_verify`，规则仅校验证据引用、来源范围与禁止主张。无 Key、超时、网络失败或非法 JSON 时显式返回生成失败，不以规则正文冒充本次模型输出。

## 权限、来源与副作用

- 不联网、不下载论文全文、不读用户文件；相关工作只引用已保存的受限来源元数据/摘要。
- 不写论文文件、不导出 DOCX/LaTex、不执行代码、不安装依赖；只在用户主动调用时返回 API 响应。

## 失败与规则降级

没有实验事实时仍返回安全蓝图：实验章节和投稿就绪度均为 `to_verify`，不会编造结果。已保存的用户实验文本仅作为“用户报告事实”，不等于独立复核。

## 测试样例

- `tests/test_research_paper_workflow.py`：无结果缺口、实验事实追溯和无自动检索。
- `tests/test_research_skill_contract_docs.py`：统一 Skill 契约与非目标说明。

## 外部参考与许可证

借鉴结构化研究工作流的可追溯性，不复制任何外部论文写作 Skill、Prompt 或模板；未引入新的第三方依赖。
