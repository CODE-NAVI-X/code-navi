# 受限证据引用与完整性检查

## 版本

`citation-scaffold.v1.1`

## 用途

将当前会话中用户主动保存和选择的 `ConversationEvidenceBundle` 来源转化为引用占位、来源—章节映射和人工核验清单。结果用于作者与导师核对，不声称来源支持了正文主张，也不声称符合任何投稿格式。

## 输入与输出

输入为当前会话已保存的论文元数据/摘要范围、用户明确选择的论文、目标文档、章节、段落锚点和人工插入状态。输出包括 `CitationCandidate`、`SelectedCitation`、`ReferenceEntryDraft` 与 `CitationQualityCheck`。章节映射只表示用户建立了关联，标为 `inference`；缺失元数据、摘要范围不足和人工核验项标为 `to_verify`。

## 规则层与模型层边界

规则层负责会话归属校验、用户选择、持久化、占位生成、重复检测、章节映射和 `fact / inference / to_verify` 边界。当前完全规则化；无模型或模型失败不影响检查，模型不得补全作者、年份、DOI、期刊、页码、引用次数或论文结论。

## 权限、来源与副作用

不联网、不读论文全文、不执行代码、不写入用户项目、不自动插入或改写原稿。只读取当前会话已保存的受限来源与用户明确选择；检查必须由用户点击触发，刷新只恢复历史结果。`inserted` 仅表示用户主动标记为已人工处理。

## 失败与规则降级

找不到会话、证据包或论文时明确返回 404；没有已选来源时返回带解释的安全空状态。作者、年份、来源链接、DOI/arXiv 标识缺失，或只有元数据没有摘要时，均保留现有值并输出 `to_verify`，不伪造完整引用或摘要支持范围。

## 测试样例

选择已保存 arXiv 来源并关联“相关工作”后，可显式运行检查并恢复历史结果；重复选择、未确认人工插入和元数据缺失会进入核验清单。跨会话来源不可见，检查不得触发学术检索或修改论文原文。

## 外部参考与许可证

仅复用项目内 EvidenceBundle 的来源追溯原则；未复制第三方引用管理器、样式、BibTeX 模板、代码或 Prompt，也没有新增依赖。
