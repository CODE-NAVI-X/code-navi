# 受限证据引用占位

## 版本

`citation-scaffold.v1`

## 用途

将用户在当前会话中主动保存的 `ConversationEvidenceBundle` 论文元数据与摘要范围，转化为可查看、可取消的引用占位和参考文献雏形；不是参考文献格式化器。

## 输入与输出

输入是当前会话的已保存证据、用户选中的 `evidence_bundle_id + paper_url`、目标文档/章节和段落锚点。输出为确定性 `CitationCandidate`、持久化 `SelectedCitation` 和 `ReferenceEntryDraft`。仅生成例如 `(作者, 年份)` 或 `[引用待核对：标题]` 的可读占位，不修改初稿、修订稿或蓝图正文。

## 规则层与模型层边界

规则层验证来源属于当前会话、记录用户选择、保存状态、列出缺失元数据和生成 `fact / to_verify` 边界。第一版不调用模型；模型不得补全作者、年份、DOI、刊物、页码或论文结论。

## 权限、来源与副作用

不联网、不读论文全文、不执行代码、不写入用户项目。允许来源仅为已保存 EvidenceBundle 的受限检索元数据/摘要；只有用户主动选择后才持久化本地引用选择。`inserted` 只表示用户已处理建议位置，不会由服务端自动插入文本。

## 失败与规则降级

找不到会话、证据包或论文时明确返回 404；没有选择来源时参考文献雏形为空。缺作者、年份、来源或 DOI/arXiv 标识时保留现有值，并标记 `to_verify`，绝不伪造完整参考文献。

## 测试样例

保存一条 arXiv 元数据后，显式选择“相关工作 / 相关工作-1”，得到可追溯占位和条目；取消选择后条目不再返回。缺作者/年份/来源/标识时断言待核对项存在，并断言不会触发学术检索。

## 外部参考与许可证

采用本项目现有受限 EvidenceBundle 的来源追溯原则；未复制第三方引用管理器、样式文件、BibTeX 模板、代码或 Prompt，也没有新增依赖。
