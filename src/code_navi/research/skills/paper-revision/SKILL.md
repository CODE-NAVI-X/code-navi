# 人工确认的论文修订预览

## 版本

`paper-revision.v2`

## 用途

为用户明确接受的单条 `RevisionTask` 生成可定位候选段落；用户再次确认或手动编辑后才创建可比较、可回退的新版本。

## 输入与输出

输入为已接受的 `RevisionTask`、原 `PaperDraft` 和 `RevisionSuggestion`；输出为含原文片段、候选、依据与待验证项的建议，及用户确认后生成的 `PaperRevision`（父版本、任务/建议 ID、diff）。

## 规则层与模型层边界

规则层决定任务接受状态、段落定位、版本保存、原稿不可覆盖、用户确认与事实边界。模型仅在严格 JSON 校验通过后补充候选措辞、理由和待验证项，不能补造引用、实验数值、样本量、显著性或结论。

## 权限、来源与副作用

不联网、不写入用户项目、不下载、不安装依赖、不执行代码。用户可编辑候选，但只有明确接受才落入新版本；当前不支持 DOCX/PDF 导入或最终格式导出。

## 失败与规则降级

未接受任务、定位失败、模型非法 JSON 或候选越过事实边界时回退规则候选或明确拒绝落版；不自动批量改稿。

## 测试样例

未接受任务时生成候选应失败；接受单个任务后生成候选；手动编辑并接受后创建新版本，保留原文、父版本、任务/建议 ID、变更依据和 diff。

## 外部参考与许可证

采用本项目可追溯版本预览原则，不复制外部审稿/改写框架、代码或 Prompt；无新增第三方依赖。
